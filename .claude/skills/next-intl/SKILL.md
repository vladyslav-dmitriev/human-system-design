# next-intl

Приоритет у правил репозитория (`CLAUDE.md`). Для точного API Next 16 + next-intl 4 сверяйся с документацией (context7, если установлен).

## Где что лежит

- Локали и сообщения: `packages/i18n/src/messages/<locale>/` (сейчас `en`, `uk`); конфиг маршрутизации: `packages/i18n/src/config`, экспорт `routing` из `@repo/i18n`.
- Запрос и навигация в приложении: `apps/web/i18n/request.ts`, `apps/web/i18n/navigation.ts`.
- Перехват запросов: `apps/web/proxy.ts` (в Next 16 это замена `middleware.ts`), комбинирует auth-проверку и `createMiddleware(routing)`.
- Синхронизация переводов идёт через Crowdin: не удаляй и не переименовывай существующие ключи без необходимости.

## Правила

1. Никаких захардкоженных пользовательских строк, включая `placeholder`, `aria-label`, `alt`, `title`, сообщения zod и toast.
2. Новый ключ добавляй **во все локали** в одном изменении. Ключи группируй по фиче (`namespace`), используй существующий стиль имён.
3. Серверные компоненты: `getTranslations("ns")` (async). Клиентские: `useTranslations("ns")`. Не делай компонент клиентским только ради переводов.
4. Страницы и layout в `app/[locale]`: вызывай `setRequestLocale(locale)` для статической генерации, `params` в Next 16 это `Promise`: `const { locale } = await params`.
5. Ссылки и редиректы: `Link`, `redirect`, `useRouter`, `usePathname` из `i18n/navigation`, а не из `next/link` / `next/navigation`, чтобы сохранялась локаль.
6. Подстановки и множественные числа через ICU-синтаксис (`{count, plural, one {# item} other {# items}}`), не конкатенацией строк.
7. Даты, числа, валюта: `useFormatter` / `getFormatter` (`format.dateTime`, `format.number`), не `toLocaleString` вручную.
8. Сообщения валидации (zod / react-hook-form): храни ключ в схеме и переводи при отображении, чтобы смена локали работала.
9. Тексты, приходящие с API (ошибки), сопоставляй с ключами по коду ошибки, а не показывай сырой текст бэкенда.
10. `generateMetadata` тоже переводится (`title`, `description`).

## Проверка

- Нет ли ключей, присутствующих в одной локали, но отсутствующих в другой.
- Нет ли `console.log` и строк в JSX кириллицей или латиницей, не прошедших через `t()`.
- Переключи локаль в браузере и пройди изменённый экран.
